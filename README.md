# kleshart

«Рассеяние» и «Вихрь» в одном приложении, с живой камерой и захватом звука.
Все файлы лежат в одной папке — их можно загрузить на GitHub прямо с телефона.

## Выложить с iPhone (GitHub Pages, бесплатно)

1. **Распакуйте архив.** В приложении «Файлы» коснитесь `kleshart.zip` — рядом появится папка `kleshart`.
2. **Создайте репозиторий.** В Safari откройте github.com/new (приложение GitHub загружать файлы не умеет). Имя — `kleshart`, видимость — **Public**, остальное не трогайте → «Create repository».
3. **Загрузите файлы.** На странице пустого репозитория нажмите ссылку **uploading an existing file**. Если её не видно, в Safari нажмите «аА» → «Запросить настольный веб-сайт».
   «choose your files» → «Выбрать файлы» → откройте папку `kleshart` → «Выбрать» → «Выбрать все» → «Открыть». Дождитесь, пока загрузятся все файлы (самые большие — по 13 МБ), и нажмите **Commit changes**.
4. **Включите сайт.** Settings → Pages → Source: «Deploy from a branch», Branch: `main`, папка `/ (root)` → Save.
5. Через 1–2 минуты сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/kleshart/` (ссылка появится вверху страницы Pages).
6. **Как приложение:** откройте сайт в Safari → «Поделиться» → «На экран „Домой“».

## С компьютера

То же самое, только на шаге 3 просто перетащите все файлы из папки в окно загрузки. Подойдёт и любой другой хостинг статических файлов с HTTPS.

## Важно

- Нужен HTTPS (на GitHub Pages он есть): без него браузер не даст камеру и микрофон.
- Открывать `index.html` двойным щелчком нельзя. Проверка на компьютере: `python3 -m http.server 8000` в этой папке и `http://localhost:8000`.
- iPhone в беззвучном режиме глушит синтезатор — переключите на звук.
- Звук вкладки или системы — только на компьютере в Chrome или Edge.
